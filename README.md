# Stock Portfolio Tracker

## Project Description

This is a Python-based Stock Portfolio Tracker developed as part of the CodeAlpha Python Programming Internship.

The program allows users to enter stock names and quantities, calculates the total investment, and saves the summary in a text file.

## Features

- Add multiple stocks
- Calculates total investment
- Uses predefined stock prices
- Saves investment summary in a text file
- Input validation

## Technologies Used

- Python 3

## Concepts Used

- Dictionary
- Loops
- If-Else
- File Handling
- Exception Handling
- User Input

## How to Run

bash
python stock_portfolio.py
